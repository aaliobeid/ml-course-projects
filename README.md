# Machine Learning Course Projects

A collection of small machine learning projects and experiments completed while learning classical machine learning algorithms with Python and scikit-learn.

These projects are based primarily on concepts taught in Krish Naik's Machine Learning Bootcamp on Udemy, along with additional experimentation and personal exploration.

The goal of this repository is to document my learning journey, strengthen my understanding of machine learning fundamentals, and practice applying algorithms to small datasets.

## Repository Contents

This repository includes projects related to topics such as:

* Simple Linear Regression
* Multiple Linear Regression
* Polynomial Regression
* Logistic Regression
* Decision Trees
* Random Forest
* Support Vector Machines
* K-Nearest Neighbors
* Clustering
* Model Evaluation
* Feature Engineering
* Data Preprocessing

More projects will be added as I continue learning.

## Technologies Used

* Python
* NumPy
* pandas
* Matplotlib
* Seaborn
* scikit-learn
* Jupyter Notebook
  
## Learning Goals

Through these projects, I aim to:

* Understand how classical machine learning algorithms work
* Learn how to prepare datasets for training
* Select suitable evaluation metrics
* Interpret model performance
* Improve my data analysis and visualization skills
* Build a strong foundation before moving to larger projects
